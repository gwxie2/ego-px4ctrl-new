# 深度图噪声示意

这张图用同一张合成深度场景，分别叠加 clean、mild、extreme 三种退化，帮助直观看出噪声对建模的影响。

![depth noise schematic](depth_noise_schematic.png)

下面这一张会更接近真实深度相机的观感：同一场景下给出原始深度图、加入噪声后的深度图，以及经过空洞修补和边界平滑后的重建结果。

![real depth reconstruction schematic](real_depth_reconstruction_schematic.png)

## 怎么看

- clean：深度边界连续，障碍轮廓清晰，适合稳定建图。
- mild：出现轻度随机波动、少量空洞和量化台阶，建图会开始抖动，但整体结构仍然可识别。
- extreme：噪声、空洞和量化都明显增强，局部结构会被破坏，容易让局部地图出现断裂或误判。

## 是否真实

这是一个“工程上可信”的合成噪声模型，不是逐帧实测标定出来的物理真值噪声。

它比较真实的地方在于：

- 会随距离增加而变差。
- 会在边缘区域更容易出现空洞。
- 会引入量化台阶和随机缺失。

它不够真实的地方在于：

- 没有严格按某一款真实深度相机做标定。
- 没有引入完整的时序相关噪声、滚动快门或复杂光照模型。

所以它适合做鲁棒性和退化趋势分析，但不适合直接当作硬件级的精确传感器仿真。

如果你更关心“重建后大概还能不能看出障碍轮廓”，就优先看第二张图。它展示的是一种很常见的工程流程：先把噪声深度做空洞修补，再做轻度平滑，最后保留大致的几何轮廓用于规划。
