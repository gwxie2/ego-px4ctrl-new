# swarm_benchmark_forest 协议

## 总体约定
- 目标：构建一个 40m x 40m x 5m 的 Gazebo 仿真世界，用于多机 VINS 漂移评估与 Ego-Planner-v2 避障测试。
- 仿真风格：优先保证视觉纹理丰富、结构清晰、便于复现与回退。
- 文件命名：主世界文件使用 `swarm_benchmark_forest_phaseN.world`。派生版本请在文件名中添加易识别后缀，例如 `_6UAV` 表示六架无人机版本（例如 `swarm_benchmark_forest_phase3_6UAV.world`）。
- 生成方式：优先使用“基座 world + 追加块”的生成策略，并用独立脚本输出派生版本。

## Phase 1 约定
### 世界尺寸
- 宏观边界：40m x 40m x 5m
- 原点居中，房间封闭，无屋顶

### 材质
- 地面：`Gazebo/Checkerboard`
- 墙壁：`Gazebo/Bricks`

### 圆周起飞基座
- 以世界原点为中心，半径 R = 5m
- 半径默认值改为 R = 15m，可通过生成脚本参数覆盖
- 无人机数量可配置，脚本按 `N_UAV` 生成对应数量的起始角度
- 角度展开遵循 30° 基准规则，并在大规模无人机时压缩到 `[-80°, +80°]` 范围内
- 无人机朝向圆心

### Phase 1 初始位姿
- 由脚本按无人机数量动态生成

### Phase 1 终点锚点
- 每架无人机的终点锚点位于其起点关于原点的对称点 `(x, y) -> (-x, -y)`
- 起点锚点和终点锚点都作为 world 中的可视化参考物体生成

### 视觉初始化锚点
- 每架无人机正前方 2m 处放置一个小木箱
- 材质：`Gazebo/Pioneer2Body`

## Phase 2 约定
- 在 Phase 1 基础上增加稀疏柱子林
- 分布区域：X ∈ [5, 35]，Y ∈ [-15, 15]
- 数量：15~20 根
- 材质：`Gazebo/Wood`
- 目标：保留至少 4m 以上的直线通道，便于 VINS 漂移观测
- 实现说明：最终 world 以原点居中方式落位，柱子会被重新映射到房间内部，避免越界
- 约束补充：所有 start / goal 锚点中心 2.0m 范围内禁止出现障碍物
- 障碍物尺寸调整：Phase 2 柱子半径按原方案放大 2 倍

## Phase 3 约定
- 在 Phase 2 基础上增加更密集柱子，但不添加 actor
- 目标：制造明显视觉和规划压力的静态稠密场景
- 主轴线 `y = -5, 0, 5` 保持更宽的可通行间隙
- 约束补充：所有 start / goal 锚点中心 2.0m 范围内禁止出现障碍物
- 障碍物尺寸调整：Phase 3 柱子半径采样范围扩大到原来的 2 倍

## Phase 4 约定
- 使用 ROS 1 Python 脚本进行多机目标调度
- 支持 namespace 自动映射与 LLM/JSON 接口预留
- 航线模板按与 Phase 1 一致的角度展开规则生成，确保可扩展到更大 `N_UAV`
- 现阶段实现脚本为 `scripts/swarm_commander.py`

## 实施建议
- 每个 Phase 独立生成 world 文件，便于回退
- 生成后执行 `gz sdf -k` 验证 SDF 语法
- 若需要派生版本（如 x2），请单独生成文件，不覆盖主线文件
