## 新旧文档对比

### 原文档问题

1. **结构混乱**：40+ 文档平铺在 `docs/` 目录
2. **命名不统一**：中英文混用，大小写不一致
3. **内容重复**：多个文档描述相同功能
4. **版本混杂**：Phase 1-4、Swarm V1/V2、基准测试混在一起
5. **缺少导航**：没有清晰的入口和学习路径

### 新文档改进

1. **分类清晰**：按系统概述 → 使用 → 组件 → 开发 → 进阶组织
2. **渐进式学习**：从快速开始到深入开发的完整路径
3. **版本隔离**：Phase 1-4 按顺序独立说明
4. **统一格式**：Markdown 规范，代码高亮，表格统一
5. **导航完善**：README 中心 + 文档间交叉引用
