# 项目简介

## 项目概述

**ego-px4ctrl** 是一个基于 ROS Noetic + PX4 SITL + EGO-Planner 的自主无人机导航工作区。它实现了从仿真到真实部署的完整自主飞行栈，包括：

- **轨迹规划**：基于 B 样条的 3D 在线轨迹规划（EGO-Planner）
- **位置控制**：级联 PID 飞行控制器（px4ctrl）
- **多机协同**：支持双机到集群的多无人机系统
- **感知融合**：支持真值里程计和 VINS 视觉惯性估计

## 核心特性

### 1. 模块化分层架构

```
┌─────────────────────────────────────────┐
│  任务/规划层（EGO-Planner）               │
├─────────────────────────────────────────┤
│  控制层（px4ctrl 级联 PID）               │
├─────────────────────────────────────────┤
│  适配层（clean_uav_core 胶水包）          │
├─────────────────────────────────────────┤
│  通信层（MAVROS）                        │
├─────────────────────────────────────────┤
│  仿真层（Gazebo + PX4 SITL）             │
└─────────────────────────────────────────┘
```

### 2. 渐进式开发阶段

| 阶段 | 功能 | 入口 |
|------|------|------|
| **Phase 1** | 单机仿真与控制 | `phase1_fullstack.launch` |
| **Phase 2** | 双机协同导航 | `phase2_dual_uav_stack.launch` |
| **Phase 3** | VINS 视觉里程计融合 | `phase3_dual_uav_vins_stack.launch` |
| **Phase 4** | 动态目标点更新 | `phase4_dual_uav_dynamic_goal_stack.launch` |

### 3. 集群系统

- **Swarm V1**：基于 PoseStamped 的原始集群版本
- **Swarm V2**：基于 GoalSet 和 MINCOTraj 的新一代集群系统
- 支持任意数量无人机的自动生成和配置

### 4. 基准测试框架

完整的性能评估体系，包括：
- 速度梯度测试（Phase A）
- 感知退化测试（Phase B）
- 时间-平滑权衡（Phase C）
- 极限速度探索（Stage D）
- 感知退化压力测试（Stage E）

## 技术栈

- **操作系统**：Ubuntu 20.04 LTS
- **机器人框架**：ROS Noetic
- **飞控固件**：PX4 SITL
- **物理仿真**：Gazebo 11
- **规划算法**：EGO-Planner（B 样条优化）
- **控制算法**：级联 PID + 推力模型
- **感知算法**：VINS-Fusion（可选）

## 设计原则

1. **里程计单一来源**：所有节点消费同一里程计话题，避免时间戳不一致
2. **命名空间隔离**：多机场景通过 `/uavN/` 命名空间实现话题隔离
3. **参数化配置**：所有关键参数可通过 launch 文件或 YAML 配置
4. **无 RC 模式支持**：完全软件控制，无需遥控器
5. **符号链接复用**：核心代码通过符号链接引用，便于同步上游更新

## 适用场景

- **教学演示**：自主导航、集群控制、性能评估
