# 快速入门

本文档将通过具体示例带您熟悉系统的基本操作。

## Phase 1：单机仿真

### 基础飞行

```bash
# 启动单机全栈仿真
source tools/source_phase1_env.sh
roslaunch clean_uav_core phase1_fullstack.launch
```

**预期行为**：
1. Gazebo 窗口打开，显示 iris 无人机
2. 约 10 秒后无人机自动起飞至 1.0m
3. 约 15 秒后开始飞向目标点 (5, 0, 1)
4. 到达目标后悬停

### 修改目标点

```bash
# 方法 1：通过 launch 参数
roslaunch clean_uav_core phase1_fullstack.launch \
  target_x:=3.0 target_y:=2.0 target_z:=1.5

# 方法 2：使用 RViz 2D Nav Goal
# 首先启动带 RViz 的版本
roslaunch clean_uav_core phase1_manual_goal_stack.launch
# 然后在 RViz 中使用 "2D Nav Goal" 工具点击目标位置
```

### 调整飞行速度

```bash
# 降低速度以获得更平滑的飞行
roslaunch clean_uav_core phase1_fullstack.launch \
  planner_max_vel:=1.0 \
  planner_max_acc:=2.0
```

## Phase 2：双机系统

### 启动双机仿真

**终端 1**：启动仿真层（必须先启动！）
```bash
source tools/source_phase1_env.sh
roslaunch clean_uav_core phase2_px4_multi_sim.launch gui:=false
```

等待 10-15 秒，直到 Gazebo 完全加载两个无人机模型。

**终端 2**：启动算法与控制层
```bash
source tools/source_phase1_env.sh
roslaunch clean_uav_core phase2_dual_uav_stack.launch
```

### 修改双机目标点

```bash
# 为两架无人机设置不同的目标
roslaunch clean_uav_core phase2_dual_uav_stack.launch \
  uav0_target_x:=-2.0 uav0_target_y:=3.5 uav0_target_z:=1.9 \
  uav1_target_x:=1.0 uav1_target_y:=6.5 uav1_target_z:=1.9
```

### 双机同步监控

```bash
# 监控 UAV0
rostopic echo /uav0/truth_odom/pose/pose/position

# 监控 UAV1
rostopic echo /uav1/truth_odom/pose/pose/position

# 监控双机轨迹广播
rostopic echo /swarm/broadcast_bspline
```

## 常用监控命令

### 查看系统状态

```bash
# 节点列表
rosnode list

# 话题列表
rostopic list

# 查看话题频率
rostopic hz /truth_odom        # 里程计频率
rostopic hz /position_cmd      # 控制指令频率

# 查看话题内容
rostopic echo /mavros/state -n 1
rostopic echo /position_cmd -n 1
```

### 可视化节点图

```bash
# 安装 rqt_graph
sudo apt install ros-noetic-rqt-graph

# 启动节点图
rqt_graph
```

### 查看日志

```bash
# ROS 日志
roslog

# 查看特定节点日志
rosnode info /px4ctrl
rosnode info /ego_planner_node
```

## 启动参数说明

### Phase 1 常用参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `target_x/y/z` | 5/0/1 | 目标位置（米） |
| `use_takeoff_trigger` | true | 是否自动起飞 |
| `takeoff_delay` | 8.0 | 起飞延迟（秒） |
| `planner_max_vel` | 2.0 | 最大速度（米/秒） |
| `planner_max_acc` | 3.0 | 最大加速度（米/秒²） |
| `gui` | true | 是否显示 Gazebo GUI |

### Phase 2 常用参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `uav0_target_x/y/z` | -2/3.5/1.9 | UAV0 目标 |
| `uav1_target_x/y/z` | 1/6.5/1.9 | UAV1 目标 |
| `planner_max_vel` | 2.0 | 最大速度 |
| `use_traj_broadcast` | true | 是否启用轨迹广播 |

## 典型工作流程

### 1. 开发调试流程

```bash
# 终端 1：启动仿真（headless 模式，节省资源）
roslaunch clean_uav_core phase1_fullstack.launch gui:=false

# 终端 2：监控关键话题
rostopic echo /position_cmd
rostopic hz /truth_odom

# 终端 3：修改参数后重启
# Ctrl+C 终端 1，重新运行带新参数的 launch
```

### 2. 性能评估流程

```bash
# 启动仿真
roslaunch clean_uav_core phase1_fullstack.launch

# 记录数据
rosbag record /truth_odom /position_cmd /planning/bspline \
  -O test_flight

# 回放数据
rosbag play test_flight.bag

# 分析数据（需要 pyrosbag 或 rqt_bag）
rqt_bag test_flight.bag
```

### 3. 多机测试流程

```bash
# 终端 1：仿真层（先启动，等待加载）
roslaunch clean_uav_core phase2_px4_multi_sim.launch gui:=false

# 等待 15 秒...

# 终端 2：算法层
roslaunch clean_uav_core phase2_dual_uav_stack.launch \
  uav0_target_x:=-2.0 uav0_target_y:=3.5 \
  uav1_target_x:=1.0 uav1_target_y:=6.5

# 终端 3：监控
rostopic hz /uav0/position_cmd
rostopic hz /uav1/position_cmd
```

## 故障排查快速参考

| 问题 | 可能原因 | 快速解决 |
|------|----------|----------|
| 无人机不起飞 | 未收到起飞指令 | 检查 `/px4ctrl/takeoff_land` |
| 起飞但不移动 | 规划未触发 | 检查 `/traj_start_trigger` |
| 飞行不稳定 | PID 增益过高 | 降低 `Kp/Kv` 参数 |
| 多机连接失败 | 启动顺序错误 | 先启动仿真层，等待加载 |
| IMU 频率告警 | 仿真负载过高 | 关闭 GUI 或降低模型复杂度 |
