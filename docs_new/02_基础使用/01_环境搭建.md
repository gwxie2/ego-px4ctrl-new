# 环境搭建指南

## 前置依赖验证

在开始之前，请确保以下依赖已正确安装：

```bash
# 检查 ROS 版本
rosversion -d  # 应输出 "noetic"

# 检查 Gazebo 版本
gazebo --version  # 应输出 Gazebo 11.x

# 检查 PX4 固件路径
ls ~/XTDrone/PX4_Firmware/launch/  # 应有多个 .launch 文件

# 检查 MAVROS
rospack find mavros  # 应输出 /opt/ros/noetic/share/mavros
```

## 工作区初始化

### 首次设置

```bash
# 1. 进入工作区
cd /home/guanwen/XTDrone/ego-px4ctrl-new

# 2. 设置环境变量（必须！）
source tools/source_phase1_env.sh

# 3. 构建工作区
catkin_make -j4

# 4. 验证构建成功
ls devel/lib/px4ctrl/px4ctrl_node
ls devel/lib/ego_planner/ego_planner_node
ls devel/lib/ego_planner/traj_server
```

### 环境脚本说明

`tools/source_phase1_env.sh` 脚本执行以下操作：

```bash
# 1. 加载 ROS Noetic
source /opt/ros/noetic/setup.bash

# 2. 加载工作区
source ~/XTDrone/ego-px4ctrl-new/devel/setup.bash

# 3. 添加 PX4 固件路径
export ROS_PACKAGE_PATH=$ROS_PACKAGE_PATH:\
  ~/XTDrone/PX4_Firmware:\
  ~/XTDrone/PX4_Firmware/Tools/sitl_gazebo
```

**重要**：每次打开新终端都需要执行此脚本！

### 永久环境变量（可选）

将以下内容添加到 `~/.bashrc`：

```bash
echo "source ~/XTDrone/ego-px4ctrl-new/tools/source_phase1_env.sh" >> ~/.bashrc
```

重新加载配置：

```bash
source ~/.bashrc
```

## 常见构建问题

### 问题 1：找不到 px4 包

**错误信息**：
```
Could not find package 'px4'
```

**解决方案**：
```bash
# 确保已 source 环境脚本
source tools/source_phase1_env.sh

# 重新构建
catkin_make -j4
```

### 问题 2：TakeoffLand 消息未定义

**错误信息**：
```
quadrotor_msgs/TakeoffLand: message type not found
```

**解决方案**：
```bash
# 确认使用本地 quadrotor_msgs
ls src/quadrotor_msgs/msg/TakeoffLand.msg

# 如果不存在，清理后重新构建
rm -rf build devel
catkin_make -j4
```

### 问题 3：Python 脚本无法执行

**错误信息**：
```
Permission denied: './scripts/xxx.py'
```

**解决方案**：
```bash
# 给所有 Python 脚本添加执行权限
chmod +x src/clean_uav_core/scripts/*.py
```

## 验证安装

### 完整系统测试

```bash
# 终端 1：启动全栈仿真
source tools/source_phase1_env.sh
roslaunch clean_uav_core phase1_fullstack.launch

# 终端 2：监控关键话题
source tools/source_phase1_env.sh
rostopic hz /truth_odom           # 应约 50-100 Hz
rostopic echo /mavros/state       # connected: true
rostopic echo /position_cmd       # 应有输出
```

### 单元测试

```bash
# 测试 px4ctrl 节点
rostopic pub /px4ctrl/takeoff_land quadrotor_msgs/TakeoffLand \
  "header: {stamp: now}" "takeoff_land_cmd: 1" -1

# 测试里程计适配器
rostopic echo /truth_odom -n 1
```

## IDE 配置推荐

### VSCode

推荐安装扩展：
- C/C++
- Python
- ROS
- YAML

配置 `.vscode/settings.json`：
```json
{
  "ros.distro": "noetic",
  "python.defaultInterpreterPath": "/usr/bin/python3"
}
```

### CLion

1. 打开工作区作为项目
2. 设置 CMake 参数：`-DCATKIN_DEVEL_PREFIX=...`
3. 配置 ROS 环境变量
