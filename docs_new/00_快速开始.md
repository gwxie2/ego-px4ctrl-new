# 快速开始指南

> 本文档帮助您在 10 分钟内完成环境配置并运行第一次仿真。

## 前置要求

- Ubuntu 20.04 LTS
- ROS Noetic（完整桌面版）
- PX4 Firmware（位于 `~/XTDrone/PX4_Firmware`）
- Gazebo 11.x
- MAVROS

## 5 分钟快速配置

```bash
# 1. 进入工作区
cd /home/guanwen/XTDrone/ego-px4ctrl-new

# 2. 设置环境（每个新终端都需要执行）
source tools/source_phase1_env.sh

# 3. 构建工作区（首次运行）
catkin_make -j4
```

## 3 分钟运行第一次仿真

```bash
# 启动单机全栈仿真
source tools/source_phase1_env.sh
roslaunch clean_uav_core phase1_fullstack.launch
```

观察终端输出，约 15 秒后您应该看到：
- `[clean_uav_core] truth_odom_adapter locked model 'iris'`
- `[px4ctrl] State: AUTO_TAKEOFF`
- `[clean_uav_core] traj_start_trigger published trigger`
- `[px4ctrl] State: CMD_CTRL`

此时无人机将起飞并飞向目标点 (5, 0, 1)。

## 2 分钟监控运行状态

打开新终端：

```bash
source tools/source_phase1_env.sh

# 查看无人机位置
rostopic echo /truth_odom/pose/pose/position -n 1

# 查看 PX4 连接状态
rostopic echo /mavros/state -n 1

# 查看控制指令
rostopic echo /position_cmd -n 1
```
